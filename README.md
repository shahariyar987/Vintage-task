# Vantage Tasks — Project Management UI

A front-end prototype of a Jira-style task management tool with a vintage-inspired design. It covers the core screens of a project tracker: authentication, a Kanban-style task board, and account settings.

## Pages

- **Login** and **Register** — split-screen auth pages
- **Dashboard** — board view of tasks with a sidebar navigation
- **Profile** — account settings with user details and editable fields

## Tech stack

HTML5 · CSS3 (custom properties) · Font Awesome

## Run it

No installation needed. Open `login.html` in any browser.
The forms are UI-only (no backend yet): logging in takes you straight to the dashboard.

## Project structure
